# PXUI stable ABI and GPU sharing

Source: artifact `5y36bm8pvvg9`, version 6, “PXUI Stable ABI and GPU Sharing Plan” (revision 4, 2026-11-11). The full design and acceptance criteria remain authoritative.

Goal: apps call PXUI through one stable C ABI and Rust wrapper. Rays and PXUI share the app-owned GPU device, command buffer, render pass, and submit. No measurable regression against the current all-static build.

## Phase evidence

- A0 evidence: the baseline metrics are in `pxui/docs/abi-baseline.md`; `pxui_abi` builds as both cdylib and rlib and exports `pxui_abi_version`. macOS native `cargo run -q -p gate -- abi-exports`, `cargo run -q -p gate -- deps`, and `cargo run -q -p gate -- shape` pass. Linux GNU and Windows GNU target builds pass using temporary cross-linkers; `llvm-nm --dynamic --defined-only` and Windows `objdump -p` show only `pxui_abi_version`. `cargo t -p gate parses_` covers macOS, Linux, Windows GNU and LLVM export-table formats. The native gallery baseline, golden and idle cases pass on Metal. Later Vulkan runtime qualification still requires Windows/NVIDIA and WSL/lavapipe.
- Each later phase is complete only when its artifact “Done when” conditions pass. The artifact's ABI, ownership, GPU, threading, determinism, and unchanged-golden rules apply throughout.
