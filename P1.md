# PXUI stable ABI and GPU sharing

Source: artifact `5y36bm8pvvg9`, version 6, “PXUI Stable ABI and GPU Sharing Plan” (revision 4, 2026-11-11). The full design and acceptance criteria remain authoritative.

Goal: apps call PXUI through one stable C ABI and Rust wrapper. Rays and PXUI share the app-owned GPU device, command buffer, render pass, and submit. No measurable regression against the current all-static build.

## Phase evidence

- A0 completion requires the baseline metrics in `pxui/docs/abi-baseline.md`, the `pxui_abi` cdylib/rlib exporting `pxui_abi_version`, `cargo run -p gate -- abi-exports`, and successful library builds on macOS, Windows, and WSL/Linux.
- A0 local evidence: `cargo check -p gate -p pxui_abi -p pxui_gallery --tests`, `cargo run -q -p gate -- abi-exports`, `cargo run -q -p gate -- deps`, and `cargo run -q -p gate -- shape` pass on macOS. `RAYS_SLOW=1 cargo t -p pxui_gallery abi_baseline_pages`, `cargo t -p pxui_gallery gpu_gallery_pages`, and `cargo t -p pxui_gallery gpu_gallery_idle` pass. The timings and the remaining platform qualification are recorded in `pxui/docs/abi-baseline.md`.
- Each later phase is complete only when its artifact “Done when” conditions pass. The artifact's ABI, ownership, GPU, threading, determinism, and unchanged-golden rules apply throughout.
